# Movie Library - Личная кинотека

**Автор:** Азалия Гайфарова

## Описание

Movie Library - это графическое приложение для управления личной коллекцией фильмов. Программа позволяет добавлять, просматривать, фильтровать и удалять фильмы с сохранением данных в JSON-формате.

## Основные возможности

- ✅ Добавление фильмов с указанием названия, жанра, года выпуска и рейтинга
- 📋 Отображение всех фильмов в удобной таблице
- 🔍 Фильтрация по жанру и году выпуска
- 💾 Автоматическое сохранение данных в JSON-файл
- 🛡️ Валидация ввода (год - число, рейтинг - от 0 до 10)
- 🗑️ Удаление выбранных фильмов
- 📱 Интуитивно понятный графический интерфейс

## Требования

- Python 3.8 или выше
- Tkinter (входит в стандартную библиотеку Python)
